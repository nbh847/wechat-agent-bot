# 智谱额度卡片模板

散帅于 2026-10-02 确认的固定模板。当前查询脚本和定时任务仅在 macOS 验证；Win10 尚未恢复。

## 使用约定

智谱额度的手动查询、每日 09:00 推送及查询结果转发统一使用此模板。由 `.claude/skills/glm-stats/scripts/query.mjs` 确定性渲染，Agent 直接返回原文，不自行改版、添加开场白、结尾说明或重新计算数据。以后只有散帅明确要求修改模板时才变更。

本文件是模板约定的唯一文档源；Skill、任务清单和 README 引用本文件。调整模板时同步查询脚本及必要验证。

## 数据与排版规则

- 标题、分隔线、图标、区块顺序和空行保持示例样式。进度条与“剩余”之间保留两个半角空格。
- 查询与重置时间使用北京时间 `YYYY-MM-DD HH:mm`，查询行注明时区；重置行沿用同一时区。
- 进度条固定 10 格，表示剩余额度；实心格数量为 `floor(剩余百分比 / 10)`，其余为空心格。精确比例以数值为准。
- 已用比例来自接口，剩余为 `100 - 已用`；最多保留一位小数，省略无意义的 `.0`，不根据进度条反推百分比。
- 套餐仅显示接口可识别的 Lite／Pro／Max，未知套餐不猜测，不显示套餐行。
- 区块缺少有效额度时显示“额度：未返回有效数据”和“重置：未返回”；缺少有效重置时间时仅该行显示“重置：未返回”。全部窗口无效或查询失败时返回脱敏错误，不发送示例数据或旧卡片。
- 不输出 Key、原始响应、账户标识或未经核对的额度单位，不把 Coding Plan 额度称为账户现金余额。
