## 已验证安全与失败路径

- 未授权发送者拒绝，路径越界和越界符号链接拒绝。
- 跨项目写入及红线操作进入任务绑定的一次性确认；错误码和重复确认无效。
- 只读风险分析不会误判为发布操作；读取 `.env`、密钥或 token 仍需确认。
- 执行端启动失败、无效协议、超时、取消、单任务互斥和一个等待任务均有自动化测试。
- 重启前运行中或排队任务标记为中断，不自动重跑。
- iLink 消息去重、待回复持久化和并发发送单飞均有自动化测试。
- 状态、凭证、锁、健康和日志文件权限为 `0600`；日志字段脱敏且有限轮转。
- 正式 Codex 适配器会拒绝权限组合不一致的请求；续接只读会话时显式覆盖 `sandbox_mode="read-only"`。
- 2026-08-13 使用 `/private/tmp` 独立 Git 项目验证：首次只读和连续追问复用同一 session；写任务只在目标项目创建指定文件，且写 session 不持久化。
